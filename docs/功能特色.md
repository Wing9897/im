# Intelligence Monitor

<p align="center">
  <strong>自託管 · 多源情報 · AI 規則化分析</strong><br/>
  <em>從訊號到洞察，在一台本機工作站完成</em>
</p>

---

> **封面一語**  
> 面對資訊爆發：用可擴展的來源與任務，讓 AI 依 **prompt 規則** 過濾雜訊、整理你真正要看的結果——本地優先，隱私在你手裡。

---

## 為什麼選它

| | |
|:---|:---|
| 🏗️ **架構清楚** | Input → Process → Output，層級分明、各自可擴 |
| 🎯 **任務中心** | 一切圍繞 `analysis_tasks` 統一連接與管理 |
| ✍️ **規則即 Prompt** | 多數分析任務只需寫好 prompt，即可規則化產出 |
| 🏠 **本地優先** | SQLite 單檔、本機綁定，保護私隱 |
| 📡 **訊號通用** | 同一資訊設計可覆蓋 IoT（如 MQTT）與一般文字來源 |

---

## ✨ 功能特色

### 🔌 任務與來源可擴展

新增來源適配器或分析模式，不必重做整條管線。Telegram、Discord、RSS、MQTT、Email 等先進統一訊息平面，再由任務訂閱。

### 📐 Input · Process · Output 層級分明

| 層 | 角色 | 本專案 |
|:--:|:-----|:-------|
| **Input** | 多源訊號入庫 | Collectors → `messages` |
| **Process** | 篩選、排程、AI／規則分析 | `analysis_tasks` |
| **Output** | 消費與外發 | Intelligence、Timeline、Board、提醒、Actions |

### 🧭 任務作為中心連接統一管理

任務是通用接口：下游以來源篩選／任務訂閱消費結果。來源怎麼加、儀表怎麼擺，都掛在同一套任務模型上。

### 📝 只需要 Prompt 就可以規則化的任務設計

`leaderboard`／`event` 等模式以任務的 `promptTemplate` 作為規則主體——換意圖多半改 prompt，而不是改程式。

### 👥 AI 員工參與任務

排行榜、關鍵事件、專案管理等模式各司其職；閉環 `project` 可多波工具回合消化來源積壓。詳見 [AI Staff／架構](ARCHITECTURE.md)。

### 💬 Agent 助手 · 簡單人機交互

側欄／快捷助手用自然語言查訊息、關鍵事件與日程；語音只做可替換 IO，文字路徑始終可用。契約見 [助手說明](agent/assistant.md)。

### 📊 自由設計的顯示儀表板

Ops Board 自由擺放監控牆、甘特、日曆、事件等 widget，版面持久化在本機 prefs——按作戰室需求自己排版。

### 👁️🎙️ 視覺與語音交互

地圖、時間軸、看板提供視覺復盤；瀏覽器語音輸入／朗讀降低操作摩擦。  
> 視覺與語音人機交互，是未來 AI 產品必須持續打磨的方向——本專案把它們當成一等公民入口，而不是外掛裝飾。

### 🧹 對抗資訊爆發

用任務規則與來源篩選，讓 AI **丟掉噪音、留下訊號**：按你的 prompt 與歸屬（工作集）整理成關鍵事件、排行、日程與提醒。

### ⏰ 事件提醒

語音提醒掃描即將到來的關鍵事件與用戶日程，在本機窗口內提示——規則與歸屬跟時間規劃同一套模型。

### 🔒 可以本地運作，保護私隱

預設本機服務 + SQLite；憑證加密存放。分析可走本機 Ollama，資料不必先上雲。

### 🌐 資訊設計通用至 IoT 與文字

同一套「訊息 → 任務 → 結果」可服務聊天／RSS 等文字流，也可掛 MQTT 等 IoT 訊號——來源可擴，語意層一致。
